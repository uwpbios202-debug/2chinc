## D-01 Testing (decided 11/12/2026: option 1)

Options:
1. **Read-only checks only (closest to CLAUDE.md).** No test framework. Each feature ships with a SQL check script that runs in a
   rolled-back transaction on the local database (permissions as several fictional users and organizations) and a Daily
   Number calculation check against hand-calculated examples. Nothing touches live people, payments or email.
2. **Full Part 14 testing for the Mirror only.** Adds a dev-only test runner (Node's built-in `node --test`, no new
   dependency) and a local Supabase with fictional people, plus browser checks. The lease system stays untested as CLAUDE.md says.

Recommendation: option 1 now (it covers the prompt's permission and calculation tests, which are the risky parts), option 2
when the Mirror has real users.

## D-03 Who creates an individual account (decided 11/12/2026: option 1, invite only)

Today nobody can sign up on 2ndchinc.org: the sign-in hook only emails addresses on file.
1. **Invite only (recommended to start).** A coordinator adds the person in the workspace and invites them; the person can
   also use the Mirror without an email (coordinator-assisted).
2. **Open self-registration** at `/mirror/register/` with Turnstile and a code to the email. This opens sign-up on the
   shared login system to anyone, which needs abuse limits (per hour caps, no access to anything else on the site).

## D-19 Speak instead of type (Stephen 11/12/2026: requirement; privacy rules DECIDED 11/13/2026, built in mirror-voice.js)

Requirement: phone first, small screens, as little typing as possible; every place a person can type must also take speech.
1. **Fewer typed fields.** Answers are tap choices wherever possible; free text only where the person's own words matter.
2. **Phones: the keyboard's microphone.** Every text field is a normal input/textarea (never blocked from dictation), so
   Android (Gboard) and iPhone dictation work with no code from us.
3. **Computers and tablets: our own Speak button** (mirror-ui.js `voiceInput`) beside every text field, using the browser's
   speech recognition (Chrome, Edge, Safari). Where the browser has none (Firefox), the button explains the system dictation
