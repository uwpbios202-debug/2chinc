# The Human Mirror: Site Map

All routes are under `https://2ndchinc.org/mirror/` (D-04). The spec's route names are kept after the prefix, except the life-area pages (see section B).
Access: **P** public, **I** signed-in individual (own records only), **W** workspace member of an organization (people enrolled
with that organization, consent-limited), **A** platform admin. Phase = MASTER_ROADMAP phase that builds it.
