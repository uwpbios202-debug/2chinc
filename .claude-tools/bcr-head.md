# Rotating bug check (run at the start of every session)

Stephen's rule (10/18/2026): **before answering his first prompt**, after reporting the open items from the memory note `next-session-report`,
run ONE segment of this check, report what it found in a few lines, then answer the prompt. One segment per login, rotating, so every area of the site
is checked in turn, nothing is checked twice in a row unless there is a reason, and the check stays current as the site changes.

## How to run it

1. Read the **Run log** at the bottom. The segment to run is **Next up** (below). Exception: if the last run of a segment logged an
   **OPEN** finding, re-run that segment first and say why ("warranted").
2. The check is **read-only**. Look; do not change live data, settings, emails or code. Fix nothing until Stephen says so, except a typo-sized,
   obviously safe repair in the repo, which you tell him about. Never send email, never move money, never switch a setting.
3. Use the recipes under the segment. Database reads: run every read-only query as `./.claude-tools/supa-query.sh "<SQL>"`
   (double quotes around the SQL, single quotes inside it). Never define shell functions, never use curly braces in shell commands,
   never source `.env.supabase` inline, never print tokens. The helper is read-only; ask Stephen before any INSERT, UPDATE, DELETE or DDL. Show
   counts and statuses, never people's emails, names, codes or door codes (see CLAUDE.md local-only rules). Pages: fetch with curl (status codes)
   or the Chrome tools if a browser is signed in.
4. Report in at most 6 lines: segment name, what was checked, **OK / FINDING** with the plain-language effect on tenants or owners, and a suggested fix.
5. Then update this file: add one line to the Run log, move **Next up** to the next segment in the numbered order (wrap from 12 to 1), and add any new
   thing worth checking to that segment's list. If the site gained a feature, add it to the right segment now, so the list never goes stale.
6. Commit the log update with the next real commit; do not push a commit just for the log.
7. Time box: about 5 minutes. If a check cannot be done (no browser, no token), log "SKIPPED: reason" and still advance.
