The flow

  1. Apply: applicant submits the application (an emailed code verifies them).
  2. Review: staff screen the application in Applications.
  3. Approve: approval creates the lease draft from the lease template.
  4. Draft & send: staff fill the lease terms and send it for signing.
  5. Sign: tenant signs online, then the agent countersigns.
  6. Move in: the tenant gets a resident portal sign-in and the unit shows as leased.
